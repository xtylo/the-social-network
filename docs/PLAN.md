# 8-Day Plan

Local MVP of the creator social network, built in **8 sessions of 1 hour each**.
It proves the three new technologies of the project: a **Rust** recommendation service that queries **pgvector**,
a **Node.js** API, and file uploads to **S3** (emulated with Floci).
AWS deployment, Lambda, API Gateway and a UI are documented as phase 2.

**Why category vectors instead of real embeddings:** what is being learned (HNSW index, the `<=>` operator,
querying from Rust) is the same, and it saves 1 to 2 hours of model integration.

## Architecture

1. Client (`curl`, `.http` file or k6) calls the **Node API** on `:3000`.
2. `GET /recommendations/:userId`: Node forwards to the **Rust service** on `:8080`, which queries PostgreSQL + pgvector on `:5432`.
3. `POST /interactions`: Node writes to PostgreSQL.
4. `POST /uploads/presign`: Node signs a PUT URL for **Floci** (S3) on `:4566`; the client uploads directly.

Recommendation logic (Rust):

1. User profile = average vector of the content the user liked or shared.
2. pgvector returns the 50 nearest unseen items (cosine distance).
3. Re-rank: best score first, at most 2 items per creator, return 10.
4. No profile (new user): most liked content of the last 24 hours.

## Decisions and findings

- **Floci instead of LocalStack.** Since March 2026 the LocalStack image requires an account and `LOCALSTACK_AUTH_TOKEN`. Floci needs neither and uses the same port.
- **Original project structure is kept.** `src/` is the Rust crate root (`src/src/` holds its code), `src/api` is the Node API, `src/infra` is Terraform, `loadtest/` is k6.
- **Dev container.** Merged compose file paths resolve from the repo root, so `.devcontainer/docker-compose.yml` uses `context: .devcontainer` and mounts `.`.
- **`tflocal` and `awslocal` are deprecated.** Use plain `aws` (it honors `AWS_ENDPOINT_URL`) and plain `terraform` with the endpoint set in the provider.
- **HNSW returns fewer rows than `LIMIT`.** With the index, `LIMIT 50` returned about 40 rows because `hnsw.ef_search` defaults to 40 and the "already seen" filter drops candidates. Fixed with `SET LOCAL hnsw.ef_search = 100` inside a transaction (`src/src/repository.rs`).
- **No made-up impact numbers.** The original requirements claim $300K/month and 2M interactions; the README only reports what is measured here.

## Rules to stay within the hour

- If a task is stuck for more than 15 minutes, simplify it or cut it. Day 8 is never cut.
- Cut in this order if behind: Terraform on day 6 (create the bucket with `aws s3 mb`), the quality check on day 7, then the Mocha tests (keep one).
- Not negotiable: Rust + pgvector recommendations (days 1 to 4) and measured numbers in the README (day 8).
- Commit at the end of every session, even if unfinished, with a message that says where you stopped.
